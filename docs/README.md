## 系统一分钟速览

- **是什么**：面向甲方安全团队与渗透测试人员的互联网资产侦察与管理平台——输入域名 / IP / IP 段，自动完成子域名发现、端口扫描、站点指纹、文件泄漏 / PoC 检测，并支持资产分组、持续监控与消息推送。
- **技术栈**：Python 3.6 + Flask/flask-restx（API）+ Celery/RabbitMQ（异步任务）+ MongoDB（存储）+ Nginx + Vue2 前端；外部工具 massdns（DNS 爆破）、nmap（端口 / 服务）、nuclei（PoC）、phantomjs（截图 / Wappalyzer）、ncrack（弱口令）、wih（JS 信息收集）。
- **进程形态**：web（gunicorn×3 + nginx）+ worker（Celery 双队列）+ scheduler（58 秒轮询调度）+ MongoDB + RabbitMQ；Docker 一键部署，对外端口 **5003 (HTTPS)**，默认口令 **admin/arlpass**。
- **关键源码入口**：`app/main.py`（API 装配）、`app/celerytask.py`（worker 分发）、`app/scheduler.py`（调度进程）、`app/config.py` + `config.yaml`（配置）。

## 阅读建议

1. **首次接触**：按 01 → 02 → 06 顺序，先懂功能，再看架构，最后部署上手；
2. **二次开发**：重点读 02（分层与任务链路）、03（集合与字段）、04（接口契约），并对照 01 末尾的「需求→源码追溯索引」定位代码；
3. **运维上线**：直接用 06，务必先读第 6 节「安全加固基线」（AUTH 开关、默认口令、公网暴露风险）。
